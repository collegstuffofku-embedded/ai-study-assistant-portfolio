About the project

First-year engineering students need a quick, simple way to understand new topics, prepare revision notes, and practise questions before examinations. Writing a clear prompt for an AI tool every time is time-consuming.

The problem

Students need an organised way to learn, revise and practise, but crafting an effective AI prompt each time takes effort.

Objective

To develop an AI-based Study Assistant that helps first-year engineering students understand academic topics, generate revision notes, and practise through interactive quizzes.

Expected outcome

A functional web application that helps students prepare academic content through AI-generated explanations, revision notes, and quizzes.

Three study modes

Select a card to read more. Each mode generates a prompt tailored to the topic you enter.

💡

Explain Topic

Generates a prompt for a detailed academic explanation.

The prompt asks Gemini to act as an experienced first-year engineering professor and explain the topic clearly and thoroughly with examples.
📝

Generate Revision Notes

Generates a prompt for concise, exam-oriented notes.

The prompt asks for concise, well-organised revision notes tailored to a first-year student preparing for semester exams.
🧠

Create Quiz

Generates a prompt for a five-question practice quiz.

The prompt asks Gemini to design a 5-question practice quiz at a first-year undergraduate engineering level.

The Copy Prompt workflow

This is a prompt-generation application. It prepares the prompt; the student uses the Copy Prompt button and submits it to Google Gemini, which produces the response. The application has no direct AI API integration and needs no API key.

How it works

Six steps from topic to AI-generated study material.

  1. Enter a topicType an academic topic.
  2. Select a modeExplain, revise or quiz.
  3. Generate a promptA suitable prompt is prepared.
  4. Copy the promptUse the Copy Prompt button.
  5. Submit to GeminiPaste it into Google Gemini.
  6. Get the responseGemini returns the AI-generated answer.

Project development

Practical 10.A – Mini Project 1: AI-Based Application Development.

Requirements

  • Simple, user-friendly web interface
  • Input field for academic topics
  • Three study modes
  • Automatic prompt generation
  • Working Copy Prompt feature
  • Responsive, organised interface
  • No API key requirement

Development approach

  1. Identified the need for a simple academic assistant
  2. Defined objectives, requirements and outcomes
  3. Generated the application in Gemini Canvas
  4. Built the topic input and three study modes
  5. Implemented the Copy Prompt feature
  6. Exported the application as an HTML file
  7. Opened and tested it in a web browser

Testing approach

Ohm’s Law was used as the demonstration topic for all three modes. For each mode the generated prompt was copied with Copy Prompt, submitted to Google Gemini, and Gemini’s response was observed and recorded.

Testing and results

Observations recorded in Practical 10.A using Ohm’s Law.

Explain Topic

Gemini generated a structured explanation of Ohm’s Law with an intuitive overview, concepts such as voltage, current and resistance, and relevant equations.

Revision Notes

Gemini generated organised notes with core definitions, important concepts and an essential formula sheet.

Create Quiz

Gemini generated an interactive five-question quiz with multiple-choice questions and explanations, followed by a performance summary of strengths and areas to improve.

Final quiz score
3/5

3 of 5 answers correct on the Ohm’s Law quiz.

Conclusion

The AI Study Assistant shows how AI tools and prompt engineering can be used to build a useful educational application. Developed with Google Gemini Canvas and exported as an HTML file, it gives first-year engineering students a simple way to understand concepts, prepare revision notes and test themselves through quizzes. Testing with Ohm’s Law confirmed that all three study modes work, with Gemini producing an explanation, revision notes and an interactive quiz that scored 3/5.
